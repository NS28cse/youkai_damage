# プロジェクト概要

最終更新: 2026-10-29

## 目的

あるゲームで発生するダメージ・回復の数値を記録し、分析できるようにする。

## 要件（ユーザー決定済み）

- 対象のゲーム機は画面キャプチャができないため、**別のスマホのカメラでゲーム画面を撮影**して認識する。
- 大きな動画ファイルの保存場所がないため、録画ではなく**リアルタイム**で処理する。
- 認識結果は Web ページ上に表で表示し、その場で **CSV としてダウンロード**できる。
- 数値は次の4種類に分類する。

| ラベル | 意味 | 表示色 |
|---|---|---|
| `enemy_damage` | 敵の被ダメージ | オレンジ |
| `ally_damage` | 味方の被ダメージ | オレンジ |
| `enemy_heal` | 敵の回復 | 緑 |
| `ally_heal` | 味方の回復 | 緑 |

- 正解ラベルは「種類」と「数値」のみ。キャラクターのモーションやイベントはラベルにしない。
- 数値の出現位置は種類どうしで一部重なるため、位置を判別の手がかりにはしない。

詳しい経緯と根拠は [decisions.md](decisions.md) を参照。

## システム構成（案・未確定）

```
[ゲーム機の画面] → (撮影) → [スマホのブラウザ]
                                │ カメラ映像を取得（getUserMedia）
                                ▼
                         [数値の検出 + 4種類の判別]  … 物体検出モデル（YOLO 系）
                                ▼
                         [数値の読み取り]            … 文字認識モデル（CRNN）
                                ▼
                         [重複除外]                  … 同じ数字を何度も記録しない
                                ▼
                         [表に表示 / CSV ダウンロード]
```

### 未確定の論点

- **推論をどこで行うか**: スマホのブラウザ内（TF.js / ONNX Runtime Web）か、PC のサーバーか。→ [decisions.md](decisions.md) の P1
- **サーバーの要否と技術**: FastAPI（Python）か Node.js か、そもそも初期版では不要か。→ P8
- **敵／味方を1枚の画像だけで判別できるか**: 未検証。データ収集の試験段階で確認する。→ [data_collection_plan.md](data_collection_plan.md)

## 進め方（案）

1. 撮影環境を固め、試験収集で実現性を確認する。
2. AI の学習なしの試作版を通しで動かす（色によるダメージ／回復の判定 → 数値読み取り → 重複除外 → CSV）。
3. 敵／味方の判別モデルを追加する。
4. 自動ラベル付けでデータを増やし、精度を上げる。
